# Ganesh Utsava Management System (Google Sheets + Apps Script)

This repository provides a full-stack, Google Workspace-native management system for Ganesh Utsava operations.

- **Backend**: Google Apps Script Web App (REST-like API)
- **Database**: Google Sheets tabs (one tab = one table)
- **Frontend**: Static HTML/CSS/JS SPA
- **Auth**: Sheet-backed users, roles, designations; in-memory session token in browser runtime
- **Storage**: No local persistence; all CRUD is done through Apps Script API

## 1) Google Sheet Tabs (create exactly these)

Users, Roles, Designations, FinancialYears, Events, Announcements, Banners, Donations, LadduAuctions, LadduWinners,
Certificates, CertificateTemplates, CertificateApprovals, BudgetPlans, BudgetApprovals, BudgetVersions, Expenses,
Assets, AssetAllocations, FinancialReports, ReportApprovals, Committee, Mandali, Volunteers, VolunteerTasks,
PoojaBookings, PoojaDateControl, PoojaHistory, Documents, CommunicationLogs, SupportTickets, AuditLogs.

Each table requires `id` as first column unless otherwise noted.

## 2) Deploy backend

1. Open Apps Script and create project.
2. Copy `apps-script/Code.gs` into editor.
3. Set script property `ADMIN_SHARED_SECRET`.
4. Deploy as **Web app**:
   - Execute as: Me
   - Access: Anyone with link (or your org restricted)
5. Copy Web App URL.

## 3) Run frontend

1. Open `web/index.html` in any static hosting (or Apps Script HtmlService if preferred).
2. In **Admin Config** panel, paste Web App URL + shared secret once per browser session.
3. Login with a user stored in `Users` tab.

## 4) API patterns

- `POST ?action=login`
- `POST ?action=create|update|delete|transition|custom`
- `GET ?action=list|get|dashboard|verifyCertificate|featureMatrix`

Auth uses bearer-like session token generated by Apps Script and validated on each call.

## 5) Feature delivery

All F1–F69 are represented in backend routes + sheet schema + frontend modules.
A feature map endpoint (`action=featureMatrix`) is included for implementation auditing.
